# NS2-Firmware-File-Documentation
Documenting the firmware files for Switch 2 23.0.1

# About
This repo is meant to document the file layout of the switch 2 firmware version 23.0.1, as well as identify what each folder contains. For example the folder `0400000000001045` contains the `exefs` and `romfs` of the News Applet.

*No files from the firmware itself are present here, please do not ask for or share any of them here.*
